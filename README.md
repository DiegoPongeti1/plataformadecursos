
# Next.js Course Plataform
Criando uma plataforma de cursos com Next.js, TypeScript e Tailwind CSS 
Foi utilizado aAPI do YouTube para buscar os vídeos.


## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS
